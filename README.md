# House-Price-Prediction
Predicting whether property listings in Azerbaijan have an official deed (Çıxarış). Compared 16 classifiers on 100K listings using price, area, floor, rooms and location. Best model, Extra Trees: 0.969 test AUC, 0.938 Gini, 0.902 balanced accuracy, 0.960 F1. Built with scikit-learn, XGBoost, LightGBM and CatBoost.
